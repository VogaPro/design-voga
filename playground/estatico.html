A regra de ouro

Componente nunca vê cor crua. Só bg-primary, text-muted, border-line — é isso que faz dark mode e rebrand funcionarem sem abrir um .tsx.

Se todo botão for colorido, a cor para de significar.

Como trocar a marca

  1. Abra src/styles/tokens.css.
  2. Troque --voga-accent, --voga-accent-2 e --voga-accent-soft.
  3. Rode bun run audit para conferir o contraste nos dois temas.
